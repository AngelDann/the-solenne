# THE SOLENNE · Brickell Bay, Miami

Interactive luxury real estate landing experience replicating a high-end architectural showcase with interactive floor selectors, building cutaway transitions, 3D dollhouse floor plans, and first-person room tours.

## Features
- **Interactive Tower Elevation**: Dynamic floor-by-floor selection (Floors 17–33) with real-time pricing and unit specs.
- **Cinematic Architectural Split**: Building cuts horizontally to reveal interior cross-sections upon floor selection.
- **3D Dollhouse Floor Plans**: Interactive isometric views for *Residence A* and *Sky Penthouse* with clickable room hotspots.
- **First-Person Interior Tours**: High-resolution walk-through views for living areas, chef's kitchens, master suites, and spa bathrooms.
- **Responsive & Lightweight**: Built with clean modern vanilla JavaScript, HTML5, and CSS3.
